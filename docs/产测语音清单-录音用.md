# 产测语音清单（录音用，2026-08-18 终版）

| | |
|---|---|
| 共计 | **7 条播报语音 + 1 条喇叭测试音 = 8 个 aac 文件**（2 条烧固件 + 6 条放工装卡 `voice/`） |
| 文件名 | **必须逐字一致**——硬编码在固件 `ptest_voice_clips.cpp`，改名要连带改代码 |
| 终版原则 | 每多播一条就多耗一点电；工人在 PC 跟前时**屏幕是唯一权威**。设备语音只留三类不可替代的时刻：①PC 还没建连（工装卡/上云）②关机在即 ③上云成功（工人开始操作的发令枪）。阶段完成/外设失败/人工超时等播报**全部移除**——细分原因走 PtestLastError 与本地日志到 PC 端展示 |

|---|---|---|---|---|

## 已从设备端代码删除的播报（记录口径，防止日后被加回来）

阶段完成（调焦/准成品/成品/检查/清除）——写标识是 PC 点击触发的，PC 界面即时反馈；
已产测转正常业务提示——"PC 搜得到拉不到流是已过站"写进作业指导书；
设备即将重启提示；外设逐项失败语音与循环；人工判定超时提醒（wait_judge）；
上云链逐级细分语音（4G/SIM/网络/云端/掉线五条并一条）。

**细分原因没有丢**：全部走 `PtestLastError` 属性与设备本地 `ptest.log` 到 PC 端展示，
只是不再占用喇叭和电量。

## 文件放在哪（设备端路径，2026-08-18 实现定案）

**固件内置 2 条** → 设备 rootfs 的 **`/opt/etc/audio/`** 根目录（audio 服务的
AudioRoot；量产=打进固件包，台架联调=手动拷进去即可）。

**工装卡 6 条** → 卡根目录 `voice/`。开机自动**同步**到设备
`/opt/etc/audio/ptest/` 后按相对路径播放——audio 服务拒绝绝对路径，卡上文件
不能直接播（与"自定义报警语音下载到 /opt/etc/audio/diy/"同一先例）。
换卡重启即换语音；单条缺失回落固件内置同名文件，**绝不阻塞产测流程**。

### demo 板形态（flash 型号不符 + SD 挂载不了，全部走文件路径）

两个环境变量，一个目录"代表 SD 卡"：

```sh
# ① 标志位/写号落文件（代替真 flash 加密分区；起横幅自证，产线固件禁出现）
export AOV_PTEST_FAKE_PARTITION_FILE=/var/appconfig/battery_ipc/ptest_fake_partition.bin

# ② 身份文件路径（它所在的目录 = 代表 SD 卡的目录）
export AOV_PTEST_IDENTITY_FILE=/var/appconfig/battery_ipc/ptest_card/device_info.json
```

对应目录准备成：

```
/var/appconfig/battery_ipc/ptest_card/    ← 这个目录就是"SD卡"
  device_info.json                        ← 三元组 + ptestDone + ptest 参数
  voice/                                  ← 6 条卡上语音放这里
    ptest_err_cardfile.aac  ptest_online.aac  ptest_err_cloud.aac
    ptest_start.aac  ptest_shutdown.aac  ptest_speaker.aac
```

设备起来后开机日志应看到 `[ptest][voice] synced 6 clip(s): ... -> /opt/etc/audio/ptest`。
固件内置 2 条 aac 手动拷到 `/opt/etc/audio/`。

**①的 bin 文件怎么初始化：什么都不做。** 文件不存在 = 空块 = 新板（未产测）；
首次写号自动原子生成（tmp+rename，断电不留半截块）。"擦除" = 删掉文件，
或 PC 下发清除指令（写全 0 块）。
⚠️ **不要用全 0xFF 填充**：真 NOR flash 擦除态确实全 FF，但真后端有 libsys
magic/CRC 校验把全 FF 判成"无合法块"；模拟文件存的是裸结构体、跳过了那层校验，
全 FF 会被解析成"成品标识已写"——设备误判已产测，还会上报一串乱码 FinishTime。
尺寸不符的文件（半截/旧结构）读侧按空块处理并打 size mismatch 告警，不会崩。

| 台架想要的效果 | 操作 |
|---|---|
| 全新板（未产测） | 什么都不做（或删 bin 文件） |
| 已产测板（验证跳过产测） | 跑完一轮写入成品标识，或 PC 下发 PtestWriteStage(3) |
| 返工重测 | 卡里 ptestDone 改 0（不用动 bin） |

`device_info.json` 完整样例（语音相关参数都可省，省了用默认）：

```json
{
  "productId":   "5KHBENFCX2",
  "deviceName":  "1000000003",
  "deviceSecret": "（真实密钥）",
  "region":      "china",
  "ptestDone":   0,
  "ptest": { "batteryMinPercent": 20, "autoFailRepeat": 0, "autoFailIntervalSec": 5 }
}
```
