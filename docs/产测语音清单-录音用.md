# 产测语音清单（录音用，2026-08-18 定稿）

| | |
|---|---|
| 共计 | **23 个 aac 文件**（3 条烧固件 + 20 条放工装卡 `voice/` 目录） |
| 文件名 | **必须逐字一致**——硬编码在固件 `ptest_voice_clips.cpp`，改名要连带改代码 |
| 音色约定 | 错误类是提示音色即可，不必凶；`ptest_speaker` 是被测内容要格外清晰 |

## 不需要录的（映射在代码里保留，当前产品不触发）

`ptest_err_led` / `ptest_err_white` / `ptest_err_speaker` / `ptest_err_key` /
`ptest_err_ptz` / `ptest_err_mic` / `ptest_err_ir` / `ptest_err_daynight` /
`ptest_err_battery` / `ptest_err_4gcard` / `ptest_err_sdcard` / `ptest_err_periph`

**为什么不录**：人工判定项（灯/按键/云台/喇叭/咪头）的现象裁判是工人，敲回车/空格就是反馈；
设备端只能感知"驱动调用返回错误"，而现象不对的原因树大得多（指令没到/参数错/驱动错/器件坏），
只覆盖一小片的语音会误导。自动项（电池/4G/SD）失败时 PC 屏即时红标，工人就在跟前，语音是重复信息。
外设测试期间设备**全程静默**，屏幕是唯一权威。后续产品若有设备端可判的检测，映射已就位、录了即用。
