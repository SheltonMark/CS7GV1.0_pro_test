## 0. 身份分层（先厘清，两套账号互不相干）

- **操作者身份**（本计划的登录）：工号+密码，本地 SQLite，**完全离线**（产线内网）。决定 UI 权限与审计归属。
- **软件级云凭证**（腾达后台账号，即 PC 版 App 那个登录）：软件连云用，由超级用户在设置页配置一次、本地加密存储（DPAPI），与操作者无关。

UI 惯例（沿用老软件）：无权限控件对技术员**直接隐藏**而非置灰（SW_HIDE，看不见就不会问）；登录框记住上次工号；**换班切换用户不退软件、不清产品会话与设备连接**；标题栏常显「产品 · 工号(角色)」。

安全决策（升级两处，不照搬老实现）：密码 **PBKDF2-HMAC-SHA256 加盐哈希**（Qt `QPasswordDigestor`，迭代 ≥10 万次；老软件 MD5/Base64 弃用）；**废除硬编码万能密码**（老 super_password=tenda_mfg 写死代码里）——超级用户忘密兜底 = 删除本地账户库文件回到首启建号流程（**产测台账独立存放不受影响**，写入管理员说明）；登录失败简单节流（连错 5 次锁 30 秒）。

超级用户唯一内置：首次启动强制创建并设密码，不可新建第二个、不可删除。

审计（P6）：指令流水与产测台账全部记操作者工号+角色；**维修清除/跳过测试项/profile 修改/账号操作**四类记独立审计日志（时间/工号/设备 SN/参数/原因）。

## 2. 批次划分

### track A · 登录与角色

- **P1 登录门 + 会话身份（✅ 本批，mock）**
  启动流程 = 登录 → 产品门 → 工位主界面；`Session.user`（工号/姓名/角色）；标题栏追加「工号(角色)」；导航栏底部「切换用户」（保产品会话，直接回登录页）；`--autoselect` 同时跳过登录与产品门。mock 账户在 `MockData.users`（明文，仅演示）。
- **P2 权限落 UI（✅ 本批，mock）**
  `Session.can*` 权限位对齐 §1 矩阵；现存唯一受控控件「跳过当前项」对技术员隐藏；后续新增受控入口（调试面板/导出/账号页/设置页）建的时候即挂矩阵，不回补。
- **P3 账号管理页 + 首启建号（UI mock）**
  超级用户/工程师可见（按矩阵分层）；首次启动无账户库 → 强制创建超级用户流程。
- **P4 设置页（UI mock）**
  后台 API 凭证配置（超级用户，占位）；产品 profile 编辑（超级用户；从关于页只读升级出编辑入口）。
- **P5 C++ 后端（真实实现期）**
  SQLite 账户库（与产测台账**分库分目录**）；PBKDF2 加盐哈希；失败节流；记住工号（QSettings）；忘密兜底行为写管理员说明。
- **P6 审计（真实实现期）**
  流水/台账带工号+角色两列；四类独立审计表；跳过测试项弹强制原因输入（工程师+）。
- **P7 调试面板 + 台账导出（工程师+，挂矩阵）**

### track B · 外设测试扩展（评审表 §1.3 V0.2 为准）

- **P8 4G 双 SIM 逐槽检测（成品页 UI + 编排）**
  Item=9 拆两条串行指令：`(0,1)` 测 SIM0 槽 → `(0,2)` 测 SIM1 槽，各自等结果再发下一条（§2.5 串行硬约束）。**本项超时 ≥90 秒**（切槽含最长 30s 网络检测，不沿用通用超时）。判定在 PC：`sim=absent` 是 Code=0 的事实上报，治具双槽插卡时判不良；detail 带 `,restore_failed`（Code=2）→ 红警提示**停线检查**。bars 阈值（默认 ≥2）进 profile 可配（老产测 csqval1/csqval2 双标准惯例）。UI：4G 行拆成 SIM0/SIM1 两个子结果。
- **P9 SD 读写校验（成品页 UI + 编排）**
  在位查询（Op=0）后串行追加 `Op=4, Param1=1`（1MB）；超时 30s；判定 `verify=ok` 且 `write/read ≥ profile 阈值`（默认宽松 write≥2/read≥5 MB/s，板验后收紧）；`Code=2 + data mismatch` 提示"卡座虚焊典型表现"。不与维修清除混排。
- **P10 纯 PC 三条（设备端零改）**
  ① 固件版本校验：profile 加 `expectedSwVersion/expectedHwVersion`，读 `ProductTestInfo` 比对，不一致判不良——放进入工位后的首次信息核对，与 ProductId 准入同一处；② 外电检测：电池项做两步（查电量 → 提示工人接外电 → 再查一次，`external=1` 才过）；③ 喇叭+咪头回环一步双验：P2P 拉流态下发喇叭放音（Item=7,Op=4），PC 听到 = 喇叭✓+咪头✓+音频链路✓，UI 做「放音并聆听」一个按钮 + 听到/没听到判定（调焦页现有咪头卡升级）。
- **P11 profile schema v2（P8-P10 的承载）**
  `items` 之外增加：`thresholds{cellBarsMin, sdWriteMinMBps, sdReadMinMBps}`、`expectedSwVersion`、`expectedHwVersion`。**SupportedItems 位图不动**（两项扩展都在原 Item 内，首版仍 0x6A7），交集逻辑零改动。
